# Loop Studio

11音色のシンセと、短いフレーズから約1分のループ曲を自動で作るブラウザアプリです。
音はすべて Web Audio API でその場で合成します。LLM や外部サービスは使わず、作曲はルールベースです。

## できること

- **演奏**: ピアノ・エレピ・リード・パッド・ベース・オルガン・マリンバ・プラック・チップチューン・ブラス・ストリングスの11音色。画面の鍵盤か PC キーで弾けます。
- **フレーズ入力**: 4拍のカウントインのあと、2小節（8拍）を録音します。サンプルフレーズの読み込みもできます。
- **自動アレンジ**: フレーズからキーを判定し、32小節（120BPM で約64秒）の曲を作ります。ジャンルはポップ / Lo-Fi / シンセウェーブ / フュージョンから選べます。
- **ループ再生**: 小節をクリックするとそこから再生します。5パート（リード・コード・ベース・アルペジオ・ドラム）の音色、音量、ミュート、ソロを調整できます。
- **WAV 書き出し**: 生成したループを 44.1kHz / 16bit のステレオ WAV で保存します。

## 使い方

Node.js が必要です。

```bash
npm install
npm run dev
```

ブラウザで表示された URL（通常は http://localhost:5173）を開きます。ブラウザの制限で、最初に音が出るのは画面を操作したあとです。

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動 |
| `npm run build` | 型検査をして `dist/` に本番ビルドを出力 |
| `npm run preview` | ビルド結果をローカルで確認 |
| `npm test` | テストを実行（Vitest） |

## PC キー操作

| キー | 動作 |
| --- | --- |
| `A` `S` `D` `F` `G` `H` `J` `K` | 白鍵 |
| `W` `E` `T` `Y` `U` | 黒鍵 |
| `Z` / `X` | オクターブを下げる / 上げる |

## 構成

```
index.html          画面の骨組み
src/
  main.ts           初期化とイベントの配線
  ui.ts             鍵盤・音色・ミキサー・タイムライン・ピアノロールの描画
  audio.ts          AudioContext、11音色とドラムの合成
  arranger.ts       キー判定とコード進行、32小節のアレンジ生成（DOM に触らない関数）
  player.ts         ループ再生のスケジューラと WAV 書き出し
  recorder.ts       フレーズ録音と試聴
  state.ts          アプリ全体の状態
  data.ts           音色とサンプルフレーズの定義
  types.ts          型定義
  style.css         Apple 風のスタイル（ライト / ダーク自動切替）
  arranger.test.ts  アレンジのテスト
```

## 制限

- 元フレーズは2小節（8拍）までです。
- WAV 書き出しは、約1分ぶんを一度に合成するので、数十秒かかることがあります。

## 技術

TypeScript（strict）、Vite、Vitest。フレームワークや UI ライブラリは使っていません。
